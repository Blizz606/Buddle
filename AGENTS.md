# Projektregeln

- Für jeden Commit einen kurzen Eintrag in `Development Blog.md` erstellen.
- Jedem Eintrag einen passenden Screenshot unter `Documentation/Screenshots/` hinzufügen und im Markdown per relativer Bildreferenz verlinken.
- Screenshots ausschließlich außerhalb von `Assets/` speichern, damit sie die Größe des finalen Unity-Builds nicht erhöhen.
